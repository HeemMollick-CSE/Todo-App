# To-Do List App

A simple, clean to-do list app built with plain HTML, CSS, and JavaScript. No frameworks or installs needed.

## Features

- Add new tasks
- Mark tasks as done or not done
- Delete tasks
- Filter by All, Active, or Done
- Clear all completed tasks at once
- Tasks are saved in your browser, so they're still there after a refresh

## Project Structure

```
todo-app/
├── index.html   # Page layout
├── style.css    # Styling
├── script.js    # App logic
└── README.md
```

## Getting Started

1. Download or clone this repository:
   ```bash
   git clone https://github.com/HeemMollick-CSE/todo-app.git
   ```
2. Open the `todo-app` folder.
3. Double-click `index.html` to open it in your browser.
